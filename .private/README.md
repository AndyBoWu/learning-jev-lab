# Local private workspace

This directory is reserved for **local-only project notes and planning** that should not be committed to this public repository.

All files under `.private/` are ignored by Git except this README.

Suggested local notes include:

- growth and launch strategy
- promotion / distribution planning
- private brainstorming
- internal TODOs that are not appropriate for the public roadmap

For the current repository-growth discussion, keep the detailed notes locally in:

```text
.private/100-stars-strategy.md
```

Do not use this directory as a secrets manager. API keys and credentials should remain in the appropriate ignored environment files or a dedicated secrets-management system.
